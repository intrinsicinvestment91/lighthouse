Lighthouse

A persistent, graph-based intelligence platform that watches public signals, connects related evidence, and surfaces only high-confidence findings.

Operational as of May 2026 Running on Start9 home server. SEC, ADSB, flight, and correlation flows are producing real signals. Graph persistence and weighted scoring are live.

What Lighthouse Does

Lighthouse watches multiple public data sources — SEC filings, aircraft transponder data, research publications, government newsrooms — and automatically finds patterns that would take hours to spot manually.

Targets → Collectors → Alerts → Correlations → Graph → MCP / CLI / Nostr

It does not try to publish everything. It is designed to filter noise and only surface events where multiple independent signals point to the same entity at the same time.

What It Watches Today

SEC Filings

Material event 8-K filings from watched companies via EDGAR full-text search. Flags items 1.01, 1.02, 2.01, 5.02, 8.01.

Military Aviation

Aircraft transponder data (ADSB) and OpenSky flight data around key defense facilities. Detects AE-range military hex codes and known callsign prefixes.

Research Publications

arXiv paper activity for a tracked roster of researchers. Flags unusual silence after a publication threshold.

Government Newsrooms

DoD, NASA, DoE newsroom archives via RSS feeds and HTML fallback. Archived locally and pinned to IPFS.

Narrative Analysis

LLM-scored urgency and specificity on archived press releases. Detects tone shifts (requires Anthropic API key).

Patents

Patent filing rate anomalies and USPTO searches. Currently gracefully degraded — patent provider is disabled by default pending a confirmed ODP adapter.
