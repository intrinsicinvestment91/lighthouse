Signal Sources

What each collector watches, why it matters, and current status and limitations.

SEC Filings

Modulemodules/sec_sentinel.py
StatusLive
Data sourceSEC EDGAR full-text search API (no auth required)

What it collects

Material event 8-K filings from watched companies. Flags specific items: 1.01 (material agreements), 1.02 (terminations), 2.01 (acquisitions), 5.02 (director/officer changes), 8.01 (other material events).

Why it matters

8-K items 1.01 and 2.01 often signal government contract awards, joint ventures, or acquisitions involving defense or aerospace contractors. When combined with ADSB military aviation activity near the same facility in the same week, the correlation is meaningful.

Known limitations

Alert deduplication uses stable filing identity (accession number + company + form type). Entity matching relies on CIK-based EDGAR submissions API lookups rather than text search, reducing false positives from similarly named entities.

Future improvements

Per-entity EDGAR CIK validation before each production run. Improved item classification for 8-K subtypes.

ADSB (Aircraft Transponder Data)

Modulemodules/adsb_sentinel.py
StatusLive — strongest signal source
Data sourceadsb.lol community feed (no API key required for community tier)

What it collects

Real-time aircraft transponder data around 7 configured facilities. Flags aircraft with:

  • ICAO hex codes in the AE-range (U.S. military aircraft, hard evidence)
  • Known military-style callsign prefixes (PAT, RCH, REACH, MUSL, ZEUS, OTIS, ELVIS, NOBLE, DUKE, etc.)
  • The upstream military=true flag from the feed

Why it matters

Military aircraft near defense research facilities are operationally significant. Recurrent callsigns (the same callsign at the same facility across multiple runs) may indicate routine operational activity or a specific program. ADSB + SEC correlations have been the strongest live signal in production runs.

Known limitations

AE-range classification is hard evidence. Callsign-prefix classification is a soft hint — it does not prove the aircraft is military-assigned, only that the callsign format matches known patterns. Facility coverage depends on the adsb.lol feed's geographic availability.

Future improvements

Graph-native callsigns (Packet planned): recurring callsigns become first-class graph entities, enabling temporal pattern analysis — "this callsign has appeared at this facility on 3 Tuesdays this month."

Flight Tracker (OpenSky)

Modulemodules/flight_tracker.py
StatusLive
Data sourceOpenSky Network API (anonymous: 10 req/10s; authenticated: 100 req/10s)

What it collects

Flight data around key facilities, with the same military/interesting classification as the ADSB sentinel. Includes callsign enrichment metadata from modules/callsigns.py.

Why it matters

Complements the ADSB feed with different geographic and aircraft coverage. OpenSky can cover aircraft that adsb.lol misses in some regions.

Known limitations

Anonymous rate limits are restrictive. Set OPENSKY_USER/OPENSKY_PASS for the authenticated tier.

arXiv Research Sentinel

Modulemodules/arxiv_sentinel.py
StatusLive
Data sourcearXiv Atom API (no auth required)

What it collects

Publication activity for a tracked roster of researchers (from seed/researchers.json). Flags unusual silence when a frequently-publishing researcher stops publishing past a threshold.

Why it matters

Research silence can precede classified work, NDA periods, or program transitions. Combined with SEC or ADSB signals, arXiv silence adds corroborating context to a correlation event.

Known limitations

May hit rate limits (HTTP 429). This is non-blocking — the module skips and logs. Per-researcher cadence baselines are not yet implemented, so silence thresholds are not individually calibrated.

Future improvements

Per-researcher cadence baselines and individually calibrated silence thresholds.

Archive / Wayback

Modulemodules/wayback_archiver.py
StatusPartial — feed-first; DoE HTML-only
Data sourceDoD, NASA, DoE newsroom websites (Playwright + RSS)

What it collects

Press releases and news pages from government agency newsrooms. Archives pages locally and optionally pins to IPFS. Uses RSS/Atom feed-first discovery with HTML link fallback.

Why it matters

Agency press releases often precede or follow significant program events. Archiving them creates a persistent record and feeds the narrative analyzer.

Known limitations

DoD (defense.gov) has redirected to war.gov — the archiver follows the redirect transparently but the config should be updated once a canonical URL is confirmed. DoE has no verified RSS feed yet — HTML selector fallback is less reliable. IPFS must be running locally for pinning; without it, pages save locally only.

Narrative Analyzer

Modulemodules/narrative_analyzer.py
StatusOptional — requires ANTHROPIC_API_KEY
Data sourceArchived press releases (output of wayback_archiver)

What it collects

LLM-scored urgency and specificity for each archived press release. Flags tone shifts — press releases that are significantly more urgent or specific than the baseline for that agency.

Why it matters

A sudden change in agency communication tone can indicate an upcoming announcement or operational change before it becomes publicly known. The signal is weak on its own but can add weight to multi-source correlations.

Known limitations

Quality is limited mainly by archive source quality, not the analyzer itself. Without ANTHROPIC_API_KEY, this module is skipped entirely. The model is claude-haiku-4-5-20251001 by default (configurable in narrative_cfg.model).

LLM use is isolated to the edge Narrative analysis is the only place Lighthouse uses an LLM. The core pipeline (correlation, scoring, graph, explanation) is fully deterministic. No LLM is used in the pipeline core.

Patent Sentinel

Modulemodules/patent_sentinel.py
StatusGracefully disabled by default
Data sourceUSPTO PatentsView (decommissioned) / USPTO ODP (planned)

What it collects

Patent filings by watched assignees, and patent filing velocity anomalies (spikes >2σ or unusual freezes by IPC class).

Why it matters

A surge of patent filings in a specific technology class by a defense contractor can signal a technology maturation event. Combined with SEC and ADSB signals, patent velocity adds longer-term context.

Current status

The old PatentsView API endpoint (search.patentsview.org) was decommissioned in 2026. The default provider is disabled, which produces no errors and no output. The pipeline continues normally.

To re-enable: PATENT_PROVIDER=legacy_patentsview (requires a working endpoint). A future odp provider will implement the USPTO Open Data Portal adapter once the schema is confirmed.

Future improvements

USPTO ODP adapter implementation. This is lower priority than graph and callsign work while the provider is gracefully disabled.
