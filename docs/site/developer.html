Developer Guide

Onboarding guide for developers extending, debugging, or integrating Lighthouse.

Setup

git clone <repo>
cd pattern-match-sentinel
pip install -e ".[dev]"
python -m playwright install chromium
pre-commit install

For the MCP server / portal:

pip install -e ".[portal]"
uvicorn portal.app:app --host 0.0.0.0 --port 8080

Running Tests

# Full unit suite (clean — no publishing credentials)
env -u NOSTR_PRIVATE_KEY_HEX -u NOSTR_PUBLISH_CORRELATIONS \
  pytest tests/unit -v --tb=short

# Single test file
pytest tests/unit/test_velocity_tracker.py -v

# Integration tests (live APIs — skip in CI by default)
pytest tests/integration -m integration -v

All tests are async-native (asyncio_mode = "auto" in pyproject.toml). Tests that call async functions must be async def. No @pytest.mark.asyncio needed.

Current unit test count: 2455 passing. (Canonical count: docs/ROADMAP_STATUS.md.)

Test Fixtures

tests/conftest.py provides shared fixtures:

  • tmp_db — temp-file SQLite with state_db schema from init_db(). Does NOT include the alerts table — tests needing it must call db.init_alerts_table().
  • tmp_db_path — path to the temp SQLite file
  • sample_uspto_raw, sample_wipo_raw — patent API response fixtures
  • nostr_test_key_hex — test Nostr private key

Core Invariants — Do Not Break

  • No DB writes during dry-run
  • No live network calls in unit tests
  • All alert persistence goes through AlertRecord + db.insert_alert()
  • All graph writes go through db.upsert_graph_node / db.upsert_graph_edge
  • No LLM in the deterministic core (narrative module is the isolated exception)
  • No import-time config singleton coupling — use getter functions
  • No global mutable state in modules
  • No logging.basicConfig in module code — modules use logging.getLogger(__name__) only
  • No graph writes in the MCP layer
  • No DB schema changes without migration safety (_ensure_alerts_column pattern)

Config Pattern

Access config via getter functions. Do not import config singleton objects directly in modules (main.py is the exception).

# Correct
from config import get_sec_cfg
cfg = get_sec_cfg()

# Wrong — couples module to import-time singleton
from config import sec_cfg

All data output paths use _data_path(rel) (delegates to modules/data_paths.py):

# Correct — respects LIGHTHOUSE_DATA_DIR
output_dir: Path = field(default_factory=lambda: _data_path("flights"))

# Wrong — hardcodes path
output_dir: str = "data/flights"

How to Add a Packet

  1. Review ROADMAP_STATUS.md and FUTURE_PLAN.md for current direction and guardrails
  2. Identify which module(s) change and what the data contract impact is
  3. Write unit tests first — no live network calls
  4. Implement the change in small increments — never rewrite a module wholesale
  5. Validate: make test, make lint, dry-run
  6. Update ROADMAP_STATUS.md with packet status
  7. Update the test count in docs/ROADMAP_STATUS.md if tests were added

Code Style

  • Python 3.11+, line length 100
  • ruff rules: E, F, I, UP, B, SIM
  • Format: ruff format + ruff check --fix
  • No comments unless the WHY is non-obvious
  • No multi-line docstrings
  • No backwards-compatibility shims for removed code
ruff check .
ruff format --check .
